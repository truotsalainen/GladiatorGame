GLADIATOR GAME

A MonoGame-based gladiator combat prototype developed as a learning project.

About

This project is an exploration of game development using the MonoGame framework. The focus is on building a structured and maintainable game architecture while experimenting with combat systems, equipment, progression, and AI.

The goal is not to create a commercial game, but to develop practical experience with game programming concepts and software design.

Current Focus

The project currently focuses on:

Action-based combat systems
Entity and component design
Equipment and durability systems
Weapon expertise and skill progression
AI-controlled gladiator archetypes
Flexible game architecture using interfaces and services
Design Goals

The main design goal is to create systems that are:

Modular and easy to extend
Separated by responsibility
Flexible enough to support different combat styles and progression paths

The player character is designed as a customizable gladiator rather than a fixed class. Enemy gladiators use predefined archetypes to create distinct combat identities.

Technologies

MonoGame

Project Status

Early development / systems prototype.

The project is currently focused on building and testing core systems before expanding into full gameplay features.
